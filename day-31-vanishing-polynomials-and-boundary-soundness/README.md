# Day 31: Vanishing Polynomials $Z_H(X)$ Over Evaluation Domains & Boundary Constraint Security

## 1. Subgroup Roots of Unity & Algebraic Collapse
- **Arbitrary vs Subgroup Domains:** Arbitrary evaluation domains $H = \{x_1, \dots, x_n\}$ produce dense polynomials with $O(n \log^2 n)$ computation overhead and $n+1$ non-zero terms.
- **Algebraic Derivation:** When $H$ is a cyclic multiplicative subgroup generated by an $n$-th root of unity $\omega$ ($n = 2^k$):
  $$H = \{1, \omega, \omega^2, \dots, \omega^{n-1}\} \implies \forall a \in H, \; a^n = 1 \implies a^n - 1 = 0$$
- **Sparse Representation:** The full linear product collapses into a binomial with only two terms:
  $$Z_H(X) = \prod_{i=0}^{n-1} (X - \omega^i) = X^n - 1$$
- **Verifier Efficiency:** Evaluating $Z_H(\zeta)$ at a random challenge point $\zeta$ requires only $O(\log n)$ field operations via binary exponentiation.

---

## 2. Global Constraint Enforcement & Divisibility Checks
- **Soundness Identity:** Circuit constraints $C(X)$ hold at every row of the execution trace if and only if:
  $$C(X) = q(X) \cdot Z_H(X) \implies \frac{C(X)}{Z_H(X)} = q(X) \in \mathbb{F}_p[X]$$
- **Quotient Degree Bound:** For an execution trace of size $n$, $\deg(Z_H) = n$ and $\deg(C) \approx 2n$ (or $3n$ with permutation arguments), yielding $\deg(q) = \deg(C) - n$.
- **Detection of Invalid Gates:** If an execution step $\omega^k$ violates an arithmetic constraint ($C(\omega^k) \neq 0$), polynomial division produces a non-zero remainder:
  $$\frac{C(X)}{Z_H(X)} = q(X) + \frac{R(X)}{Z_H(X)}$$
  The rational fraction cannot be committed via standard polynomial commitment schemes (e.g., KZG), causing proof verification to fail.

---

## 3. Boundary & Intermediate Domain Partitioning
- **Initial Boundary Constraint:** Public input initialization enforced strictly on row 0:
  $$Z_{first}(X) = X - 1$$
- **State Transition Constraints:** Enforced across all rows except the terminal row to prevent wrap-around:
  $$Z_{H \setminus \{\omega^{n-1}\}}(X) = \frac{X^n - 1}{X - \omega^{n-1}}$$
- **Terminal Boundary Constraint:** Independent state assertion verified explicitly at step $\omega^{n-1}$:
  $$Z_{last}(X) = X - \omega^{n-1}$$

---

## 4. Security Exploits & Auditor Attack Vectors

### A. Domain Truncation Attack (Off-by-One Subgroup Order)
- **Vulnerability:** Prover/verifier parameter desynchronization where the verifier checks $Z_H(X) = X^m - 1$ with $m < n$ (e.g., $m = n/2$ or $n - 1$).
- **Impact:** Divisibility only enforces constraints on the subset of size $m$. Trace steps from $m$ to $n-1$ remain completely unconstrained, allowing arbitrary forged witness injection.

### B. Missing Boundary Root Exploit
- **Vulnerability:** Using the transition vanishing polynomial $Z_{H'}(X) = \frac{X^n - 1}{X - \omega^{n-1}}$ without implementing an explicit assertion on the excluded row $\omega^{n-1}$.
- **Impact:** The final execution state wire $w_O(\omega^{n-1})$ has zero mathematical constraint, enabling the prover to spoof terminal outcomes while generating a mathematically valid proof.

### C. Unconstrained High-Degree Power Chains
- **Vulnerability:** Decomposing $x^n - 1 = 0$ into quadratic R1CS intermediate variables ($A \cdot B = C$) without constraining intermediate terms or the final equality check.
- **Impact:** Unconstrained signals grant degrees of freedom to the prover, allowing inputs outside the roots-of-unity domain to satisfy the gate logic.

---

## 5. Auditor Checklist (Vanishing Polynomials)
1. Confirm that the verifier's power parameter $m$ in $X^m - 1$ strictly matches the trace domain size $n = 2^k$.
2. Verify that every excluded domain element in transition constraints has an accompanying boundary constraint.
3. Ensure all intermediate variables in power decomposition chains are constrained using strict equality operators.
